# 🍔 Stellar Burger

Веб-приложение для создания и оформления заказов в бургерной Stellar Burger.

Пользователь может собрать собственный бургер из доступных ингредиентов, изменить порядок ингредиентов, оформить заказ, а также просматривать ленту заказов и историю своих заказов.

Проект разработан на React + TypeScript с использованием Redux Toolkit, RTK Query, WebSocket и React DnD.

## ✨ Возможности

- просмотр доступных ингредиентов;
- просмотр подробной информации об ингредиентах;
- сборка собственного бургера;
- добавление и удаление ингредиентов;
- изменение порядка ингредиентов с помощью Drag & Drop;
- автоматический расчёт стоимости бургера;
- оформление заказа;
- просмотр номера оформленного заказа;
- регистрация и авторизация пользователей;
- редактирование данных профиля;
- просмотр истории собственных заказов;
- просмотр общей ленты заказов;
- получение обновлений статусов заказов в реальном времени через WebSocket;
- защищённые маршруты для авторизованных пользователей;
- модальные окна для отображения дополнительной информации.

## 🏗 Архитектура

Приложение построено на компонентном подходе React.

Основные части приложения:

- Components — переиспользуемые UI-компоненты;
- Pages — страницы приложения;
- Services / API — взаимодействие с сервером и RTK Query;
- Slices — Redux-состояние приложения;
- Utils — вспомогательные функции;
- E2E — end-to-end тесты Playwright.

Для удобства импортов в проекте настроены алиасы:

```
@            → src
@components  → src/components
@services    → src/utils
@pages       → src/pages
@utils       → src/utils
```

## 🔐 Авторизация

Для работы с аккаунтом пользователя реализована авторизация через API.

Авторизованный пользователь может:

- зарегистрироваться;
- войти в аккаунт;
- выйти из аккаунта;
- получить данные своего профиля;
- изменить данные профиля;
- просматривать историю своих заказов.

Для защищённых страниц используются специальные маршруты, которые проверяют состояние авторизации пользователя.

## 📡 Работа с API и WebSocket

Приложение взаимодействует с серверным API для получения ингредиентов, авторизации пользователей и создания заказов.

Для запросов и управления серверными данными используется RTK Query.

Для ленты заказов и истории заказов пользователя используется WebSocket, благодаря чему новые заказы и изменения их статусов могут отображаться без ручного обновления страницы.

## 🧪 Тестирование

В проекте используются несколько уровней тестирования.

### Unit-тесты

Для проверки Redux-логики и отдельных частей приложения используется Vitest.

Запуск:

`npm run test`

Интерфейс Vitest:

`npm run test:ui`

### E2E-тесты

Пользовательские сценарии проверяются с помощью Playwright.

Запуск всех E2E-тестов:

`npm run e2e`

Запуск Playwright в UI-режиме:

`npm run e2e:ui`

Playwright настроен для запуска тестов в Chromium, Firefox и WebKit. Для тестов автоматически запускается локальный dev-сервер Vite.

## 📦 Установка и запуск

Клонировать репозиторий:

`git clone https://github.com/AkujiSamurai/react-burger.git`

Перейти в директорию проекта:

`cd react-burger`

Установить зависимости:

`npm install`

Запустить приложение в режиме разработки:

`npm run dev`

После запуска приложение будет доступно по адресу:

http://localhost:5173

## 🔍 Проверка качества кода

Запустить все проверки:

`npm run lint`

Отдельная проверка ESLint:

`npm run eslint`

Проверка CSS:

`npm run stylelint`

`npm run prettier`

Для создания коммитов используется:

`npm run commit`

Формат сообщений коммитов соответствует Conventional Commits.
